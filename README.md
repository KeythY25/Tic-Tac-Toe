# Tic-Tac-Toe

## Description 

This project is a command-line Tic-Tac-Toe game where a human player (X) competes against an AI (O). The AI operates in Easy Mode, making random moves rather than optimal ones. This ensures a more casual and winnable experience for the player.

Features

* Single-player mode against an AI opponent.

* AI moves randomly.

* Valid move enforcement (prevents overwriting existing marks).

* Game status checks (win, draw, or continue playing).

* Simple command-line interface.

## Installation & Running the Game

**Requirements**

* Python 3.11 installed on your system.

* A command-line terminal (Windows Command Prompt, macOS Terminal, or Linux shell).

## Running the Game
```
Download the tictactoe.py file or clone the repository.

Open a terminal and navigate to the folder where the file is stored.
```
Run the game with:
```
python tictactoe.py
```
Follow the on-screen instructions to make your moves and play against the AI.

## How to Play

* The game is played on a 3x3 grid.

* You (X) and the AI (O) take turns placing symbols on the board.

* The goal is to get three of your symbols in a row (horizontal, vertical, or diagonal) before the AI.

* The game announces if you win, lose, or draw.

**User Inputs**

* Enter your move in the format:
```
row column
```
* Example: Typing 1 1 places your mark in the center.

## Game Rules

* Players take turns placing their marks (X for the player, O for the AI).

* A player wins by getting three in a row, column, or diagonal.

* The game ends in a draw if all spots are filled without a winner.
